## Key points captured
- **Runtime reduction**: presence of an AGENTS.md file was associated with a 28.64% reduction in median runtime on evaluated tasks.
- **Token reduction**: median output tokens decreased by 16.58% with AGENTS.md present.
- **Interpretation**: the results suggest that repository-level context files can improve agent efficiency along both time and token dimensions, though the handoff summary does not specify benchmark, model, or task-set details.

## Limitations

- No information on whether the effect holds across models or task types.

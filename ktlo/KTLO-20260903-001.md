## Status

Open

## Context

During WP-06 review, finding N4 identified that the `test-sync` script was not
documented in AGENTS.md. The reviewer classified this as "Nit" severity. The
human collaborator corrected this classification, establishing the policy that
missing, incomplete, or outdated documentation is a blocker in every case.

## Policy

Documentation issues are always blockers. This applies to:

- Undocumented scripts, commands, or tools
- Missing usage instructions
- Outdated documentation that does not reflect current behavior
- Missing examples or cross-references
- Any gap where "it works but is not documented" would prevent a user (human
  or agent) from effectively using the feature

## Action Required

Update the review workflow to ensure documentation issues are correctly labeled
as blockers in findings. Specifically:

1. Update reviewer instructions to classify documentation gaps as blockers
   rather than nits or minor issues.
2. Add documentation completeness checks to review criteria.
3. Ensure reviewers understand that undocumented functionality is incomplete
   functionality, regardless of whether the underlying code works correctly.

## Rationale

Documentation is part of the deliverable. Code that works but is not documented
is incomplete. Users (human or agent) cannot effectively use undocumented
features, and treating documentation gaps as low-severity issues allows
incomplete deliverables to pass review.

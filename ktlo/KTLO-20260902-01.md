## Status

Active

## Description

Current commit footers include `review-skills`, `agents`, and `models`. Future
enhancements could add:

- **domain-skills**: Track which domain skills document-author loaded during
  execution
- **review-verdicts**: Track final review verdicts from each review perspective

## Benefits

- Better traceability for debugging and analysis
- Clearer audit trail of which expertise was applied
- Easier identification of review outcomes in commit history

## Challenges

- Updating completion packet formats to capture domain-skills information
- Defining how review-verdicts should be formatted and aggregated
- Ensuring orchestrator tracks and includes this information when drafting
  commit messages
- Maintaining backward compatibility with existing commit conventions
